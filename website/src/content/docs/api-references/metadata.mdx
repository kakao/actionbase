Manage databases, tables, and aliases.

## 1. Database

### 1.1 List Databases

```
GET /graph/v3/databases
```

**Response**: `List<DatabaseDescriptor>`

### 1.2 Get Database

```
GET /graph/v3/databases/{database}
```

| Parameter | Required | Description   |
| --------- | -------- | ------------- |
| database  | Yes      | Database name |

**Response**: `DatabaseDescriptor`

Returns 404 if not found.

### 1.3 Create Database

```
POST /graph/v3/databases/{database}
```

| Parameter | Required | Description   |
| --------- | -------- | ------------- |
| database  | Yes      | Database name |

**Request Body**:

```json
{
  "database": "mydb",
  "comment": "My database"
}
```

**Response**: `DatabaseDescriptor`

### 1.4 Update Database

```
PUT /graph/v3/databases/{database}
```

**Request Body**:

```json
{
  "active": true,
  "comment": "Updated comment"
}
```

**Response**: `DatabaseDescriptor`

### 1.5 Delete Database

```
DELETE /graph/v3/databases/{database}
```

**Response**: `DatabaseDescriptor`

## 2. Table

### 2.1 List Tables

```
GET /graph/v3/databases/{database}/tables
```

**Response**: `List<TableDescriptor.Edge>`

### 2.2 Get Table

```
GET /graph/v3/databases/{database}/tables/{table}
```

**Response**: `TableDescriptor.Edge`

Returns 404 if not found.

### 2.3 Create Table

```
POST /graph/v3/databases/{database}/tables/{table}
```

**Request Body**:

```json
{
  "schema": {
    "type": "EDGE",
    "source": { "type": "STRING", "comment": "source" },
    "target": { "type": "STRING", "comment": "target" },
    "properties": [
      { "name": "score", "type": "INT", "comment": "score", "nullable": true }
    ],
    "direction": "OUT",
    "indexes": [],
    "groups": []
  },
  "storage": { "type": "HBASE", "tableName": "my-hbase-table" },
  "mode": "SYNC",
  "comment": "My table"
}
```

**Response**: `TableDescriptor.Edge`

### 2.4 Update Table

```
PUT /graph/v3/databases/{database}/tables/{table}
```

**Request Body**:

```json
{
  "active": true,
  "comment": "Updated comment",
  "mode": "ASYNC"
}
```

**Response**: `TableDescriptor.Edge`

## 3. Alias

### 3.1 List Aliases

```
GET /graph/v3/databases/{database}/aliases
```

**Response**: `List<AliasDescriptor>`

### 3.2 Get Alias

```
GET /graph/v3/databases/{database}/aliases/{alias}
```

**Response**: `AliasDescriptor`

Returns 404 if not found.

### 3.3 Create Alias

```
POST /graph/v3/databases/{database}/aliases/{alias}
```

**Request Body**:

```json
{
  "table": "target-table",
  "comment": "My alias"
}
```

**Response**: `AliasDescriptor`

### 3.4 Update Alias

```
PUT /graph/v3/databases/{database}/aliases/{alias}
```

**Request Body**:

```json
{
  "active": false,
  "table": "new-target-table",
  "comment": "Updated comment"
}
```

**Response**: `AliasDescriptor`

### 3.5 Delete Alias

Alias must be deactivated (`active: false`) before deletion.

```
DELETE /graph/v3/databases/{database}/aliases/{alias}
```

**Response**: `AliasDescriptor`
