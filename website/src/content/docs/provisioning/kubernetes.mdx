Kubernetes-based provisioning guides and best practices for Actionbase will be provided in future releases.

At Kakao, Actionbase is currently provisioned using Kubernetes. This Kubernetes-based provisioning approach will be made available to help you deploy Actionbase in production environments.

At this stage, Actionbase is being made available to help you explore and understand its capabilities. Kubernetes deployment documentation, including deployment manifests, high availability configurations, performance tuning, monitoring setup, and security best practices, will be added as the project evolves.

For now, please refer to the [Local Provisioning](/provisioning/local/) guide to get started with Actionbase locally.
