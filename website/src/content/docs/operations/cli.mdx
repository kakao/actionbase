The Actionbase CLI provides an interface for managing and maintaining Actionbase clusters. It enables direct interaction with metadata, mutation, and query operations.

## Installation

Install the Actionbase CLI using the installation script:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/kakao/actionbase/main/cli/install.sh)"
```

This script will automatically detect your operating system and architecture, download the latest release, and install it to `/usr/local/bin/actionbase`.

### Manual Installation

Alternatively, you can download the latest release binary for your platform from the [releases page](https://github.com/kakao/actionbase/releases). After downloading, make the binary executable and move it to a directory in your PATH:

```bash
chmod +x actionbase
sudo mv actionbase /usr/local/bin/
```

## Setup

The CLI requires connection information to interact with an Actionbase cluster. You can provide this via command-line flags:

```bash
actionbase --host <host-url> [--authKey <auth-key>]
```

For example:

```bash
actionbase --host http://localhost:8080 --authKey your-auth-key
```

Once connected, the CLI enters an interactive mode where you can execute commands.

## Commands

### Connection and Status

#### `status`

Show current connection status and selected database, table, and alias.

```bash
status
```

#### `help`

Display all available commands and their usage.

```bash
help
```

#### `exit`

Exit the CLI.

```bash
exit
```

For a quick walkthrough using the CLI, see [Quick Start](/quick-start/).

### Metadata Management

#### `create`

Create a database, storage, table, or alias.

```bash
# Create database
create database --name <name> --comment <comment>

# Create storage
create storage --hbaseNamespace <namespace> --hbaseTable <table> --storageType <type> --name <name> --comment <comment>

# Create table
create table --database <database> --storage <storage> --name <name> --comment <comment> --type <type> --direction <direction> --schema <schema> --indices <indices> --groups <groups>

# Create alias
create alias --database <database> --table <table> --name <name> --comment <comment>
```

#### `show`

List databases, storages, tables, indices, or groups.

```bash
# Show all databases
show databases

# Show all storages
show storages

# Show all tables
show tables

# Show indices for current table/alias
show indices --using <table|alias>

# Show groups for current table/alias
show groups --using <table|alias>
```

#### `use`

Select a database, table, or alias to use for subsequent operations.

```bash
use database <name>
use table <name>
use alias <name>
```

#### `desc`

Describe a table or alias.

```bash
desc <name> --using <table|alias>
```

### Data Operations

#### `get`

Query edges from source to target.

```bash
get --source <source> --target <target>
```

#### `scan`

Scan edges using an index.

```bash
scan --index <index> --start <start> --direction <direction> --limit <limit> [--ranges <ranges>]
```

#### `count`

Count edges for a table.

```bash
count --table <table> --start <start> --direction <direction>
```

#### `mutate`

Insert, update, or delete edges.

```bash
mutate --type <type> --table <table> --source <source> --target <target> --version <version> --properties <properties>
```

### Utilities

#### `debug`

Enable or disable debug mode.

```bash
debug on
debug off
```
