HBase configuration guides and best practices for Actionbase will be provided in future releases.

Actionbase uses HBase as its primary storage backend. HBase is a distributed, scalable, big data store that provides reliability, horizontal scalability, strong consistency guarantees, and low-latency random read/write access.

At Kakao, Actionbase is currently deployed with HBase in production environments. This HBase configuration guide will be made available to help you configure and optimize HBase for Actionbase deployments.

At this stage, Actionbase is being made available to help you explore and understand its capabilities. HBase configuration documentation, including setup instructions, configuration best practices, performance tuning guidelines, monitoring setup, and troubleshooting guides, will be added as the project evolves.

For now, please refer to the [Local Provisioning](/provisioning/local/) guide to get started with Actionbase locally, which includes instructions for running HBase locally for development and testing.
