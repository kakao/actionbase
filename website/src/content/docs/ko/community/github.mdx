액션베이스는 오픈소스이며 GitHub에서 호스팅됩니다. 커뮤니티의 기여를 환영합니다!

## 저장소

- **GitHub**: [https://github.com/kakao/actionbase](https://github.com/kakao/actionbase)
- **Issues**: [버그 신고 또는 기능 요청](https://github.com/kakao/actionbase/issues)
- **Discussions**: [질문하고 아이디어 공유하기](https://github.com/kakao/actionbase/discussions)

## 기여하기

액션베이스에 기여하는 것을 환영합니다! 다음과 같은 방법으로 도움을 주실 수 있습니다:

### 이슈 신고

버그를 발견하거나 기능을 요청하려면:

1. 중복을 피하기 위해 기존 이슈 확인
2. 다음 내용을 포함하여 새 이슈 생성:
   - 문제 또는 기능에 대한 명확한 설명
   - 재현 단계 (버그의 경우)
   - 예상 동작 vs 실제 동작
   - 환경 세부 정보 (OS, Java 버전 등)

### Pull Request 제출

1. 저장소 포크
2. 기능 브랜치 생성: `git checkout -b feature/your-feature`
3. 코드 스타일을 따라 변경사항 작성
4. 테스트 작성 또는 업데이트
5. 변경사항 커밋: `git commit -m 'Add some feature'`
6. 브랜치에 푸시: `git push origin feature/your-feature`
7. Pull Request 열기

### 코드 스타일

- 기존 코드 스타일 및 규칙 준수
- 새 기능에 대한 테스트 작성
- 필요에 따라 문서 업데이트
- 모든 테스트 통과 확인

### 개발 워크플로우

1. 개발 환경 설정 (자세한 내용은 [로컬 설정](/ko/provisioning/local/) 참조)
2. 변경사항 작성
3. 테스트 실행: `./gradlew test`
4. 프로젝트 빌드: `./gradlew build`
5. Pull Request 제출

## 도움 받기

- **문서**: 가이드 및 API 레퍼런스는 [문서](/ko/introduction/)를 확인하세요

- **Discussions**: GitHub Discussions에서 질문하세요
