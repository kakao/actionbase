Actionbase 커뮤니티에 오신 것을 환영합니다! Actionbase는 오픈소스 프로젝트이며, 전 세계 개발자들의 기여, 피드백, 참여를 환영합니다.

## 참여하기

Actionbase 커뮤니티에 참여하는 방법은 다양합니다:

- **코드 기여**: Pull Request를 제출하여 Actionbase 개선에 도움
- **이슈 신고**: 버그를 발견하고 개선 사항을 제안
- **아이디어 공유**: 토론에 참여하고 사용 사례 공유
- **문서 개선**: 문서를 더 나은 방향으로 개선
- **다른 사람 도와주기**: 질문에 답하고 커뮤니티 멤버들을 도와주기

## 커뮤니티 채널

### GitHub

Actionbase는 GitHub에서 호스팅되며, 모든 개발 활동이 여기서 이루어집니다:

- **저장소**: [https://github.com/kakao/actionbase](https://github.com/kakao/actionbase)
- **Issues**: [버그 신고 또는 기능 요청](https://github.com/kakao/actionbase/issues)
- **Discussions**: [질문하고 아이디어 공유하기](https://github.com/kakao/actionbase/discussions)

기여에 대한 자세한 정보는 [GitHub 가이드](/ko/community/github/)를 참조하세요.

## 행동 강령

우리는 모든 커뮤니티 멤버를 위한 환영하고 포용적인 환경을 제공하기 위해 노력합니다. 커뮤니티 표준과 기대사항을 이해하기 위해 [행동 강령](/ko/community/code-of-conduct/)을 읽어주세요.

## 도움 받기

- **문서**: 가이드 및 API 레퍼런스는 [문서](/ko/introduction/)를 확인하세요
- **GitHub Issues**: 기존 이슈를 검색하거나 새 이슈를 생성하세요
- **GitHub Discussions**: 커뮤니티와 질문하고 아이디어를 공유하세요

## 인정

우리는 Actionbase에 대한 모든 기여를 소중히 여기고 인정합니다. 기여자는 다음에서 인정받습니다:

- 릴리스 노트
- 기여자 목록
- 프로젝트 문서

Actionbase 커뮤니티의 일원이 되어 주셔서 감사합니다!
