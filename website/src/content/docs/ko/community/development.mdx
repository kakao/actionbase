## 사전 요구사항 {#prerequisites}

- Java 17 이상
- IntelliJ IDEA (Community 또는 Ultimate)

## 설정 방법 {#setup}

```bash
git clone https://github.com/kakao/actionbase.git
cd actionbase
```

IntelliJ에서 열기: **파일 > 열기** → 프로젝트 루트 선택

IntelliJ가 Gradle을 자동으로 임포트합니다. 인덱싱이 완료될 때까지 기다리세요.

## 빌드 {#build}

```bash
./gradlew build
```

또는 IntelliJ에서: **Gradle 패널 > actionbase > 작업 > build > build**

## 코드 포맷팅 {#format}

커밋 전에 실행하세요:

```bash
./gradlew spotlessApply
```

이 명령은 Kotlin/Java 코드를 프로젝트 스타일에 맞게 포맷합니다.

## 실행 {#run}

```bash
./gradlew :server:bootRun
```

서버는 `http://localhost:8080`에서 시작합니다.

## 테스트 {#test}

```bash
# All tests {#all-tests}
./gradlew test

# Specific module {#specific-module}
./gradlew :core:test
./gradlew :engine:test
./gradlew :server:test
```

## PR 워크플로 {#pr-workflow}

GitHub에서 [kakao/actionbase](https://github.com/kakao/actionbase)를 포크한 후 원격 저장소를 설정하세요:

```bash
git remote rename origin upstream
git remote add origin https://github.com/YOUR_USERNAME/actionbase.git
```

1. 브랜치 생성: `git checkout -b feature/your-feature`
2. 변경 사항 적용
3. 형식: `./gradlew spotlessApply`
4. 테스트: `./gradlew test`
5. 커밋: `git commit -m "feat(scope): description"`
6. 푸시 및 PR 생성
