Actionbase에 관심을 가져주셔서 감사합니다. 프로젝트를 사용하거나, 질문을 하거나, 이슈를 보고하거나, 문서를 개선하거나, 코드를 기여하는 등 모든 형태의 참여가 환영합니다.

## 협업 방식 {#how-we-collaborate}

우리는 [GitHub](https://github.com/kakao/actionbase)를 통해 협업합니다:

- **[토론](https://github.com/kakao/actionbase/discussions)**: 질문, 아이디어, 자유로운 대화
- **[이슈](https://github.com/kakao/actionbase/issues)**: 버그 신고, 기능 요청, 구체적인 개선 사항
- **[풀 리퀘스트](https://github.com/kakao/actionbase/pulls)**: 코드 및 문서 변경

질문, 아이디어, 피드백이 있으시면 [토론](https://github.com/kakao/actionbase/discussions)에서 함께해 주세요.

풀 리퀘스트는 협업하여 검토한 후 관리자가 병합합니다.

풀 리퀘스트를 제출할 때는 개인 Contributor Licensing Agreement(CLA)에 서명해 주세요. 법인용 CLA가 필요한 경우 [oss@kakaocorp.com](mailto:oss@kakaocorp.com)으로 문의해 주세요.

## 시작하기 {#getting-started}

오픈 소스가 처음이신가요? **[좋은 첫 이슈](https://github.com/kakao/actionbase/labels/good%20first%20issue)** 라벨이 붙은 이슈를 찾아보세요.

로컬 개발 환경 설정은 [개발 환경 설정](/ko/community/development/) 문서를 참고하세요.

## 보안 {#security}

보안 취약점은 공개 이슈 대신 [GitHub 보안 권고](https://github.com/kakao/actionbase/security/advisories/new)를 통해 신고해 주세요.

## 커뮤니티 기준 {#community-standards}

모든 기여자는 **[행동 강령](https://github.com/kakao/actionbase/blob/main/CODE_OF_CONDUCT.md)**을 준수해야 합니다.

프로젝트 역할에 대한 안내는 [거버넌스](/ko/community/governance/) 문서를 참고하세요.
