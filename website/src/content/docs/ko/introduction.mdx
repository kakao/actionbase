액션베이스는 대규모 사용자 활동 데이터를 처리하기 위한 고성능 그래프 데이터베이스입니다. [Kakao](/about-kakao)에서 수천만 명의 사용자에게 서비스를 제공하며 프로덕션 환경에서 검증되었습니다.

## 액션베이스란?

액션베이스는 그래프 데이터 모델을 사용하는 OLTP(Online Transaction Processing) 시스템으로, 대규모 사용자 활동 데이터 처리를 위해 특별히 설계되었습니다. HBase와 같은 스토리지 백엔드 위에 구축된 일반화된 인터페이스를 제공하여 대규모 사용자 활동 데이터를 효율적으로 저장하고 쿼리합니다. 액션베이스는 애플리케이션과의 쉬운 통합을 위한 REST API를 제공합니다.

## 프로젝트 목표

- **실시간 서빙**: 읽기 트래픽에 대해 10ms 미만의 저지연 응답
- **대규모 트래픽 처리**: 초당 수십만 건의 요청(RPS) 처리
- **대용량 데이터 관리**: 수백만 TB 규모의 데이터 저장 및 관리
- **유연한 확장성**: 수평 확장을 통한 서비스 성장에 대응

## 주요 기능

### 쓰기 시점 최적화

액션베이스는 쓰기 시점에 인덱스와 카운터를 사전 계산하여, 비용이 많이 드는 쿼리 시점 계산 없이 초고속 읽기를 가능하게 합니다. 이러한 설계 선택으로 일관된 저지연 읽기 작업을 &lt;5ms p99 지연 시간으로 제공합니다.

### 속성 그래프 모델

액션베이스는 유연한 스키마를 가진 표준 속성 그래프 데이터 모델을 지원합니다. 이를 통해 복잡한 관계와 사용자 활동 데이터를 쉽게 모델링할 수 있으며, 시간이 지나면서 데이터 모델을 진화시킬 수 있는 유연성을 유지할 수 있습니다.

### 쉬운 통합

액션베이스는 애플리케이션과의 원활한 통합을 위한 REST API와 클라이언트 라이브러리를 제공합니다. 최소한의 설정으로 빠르게 시작할 수 있으며, 기존 인프라에 액션베이스를 통합할 수 있습니다.

### 람다 아키텍처 지원

액션베이스는 벌크 로딩, 비동기 처리, 데이터 파이프라인 기능을 제공하여 실시간 및 배치 처리 시나리오 모두에 적합합니다.

## 데이터스토어

액션베이스는 현재 신뢰성과 확장성을 위해 선택된 HBase를 스토리지 레이어로 사용합니다. 향후 릴리스에서는 SlateDB를 포함한 추가 스토리지 백엔드를 지원할 예정입니다.

## 프로덕션 사용

액션베이스는 KakaoTalk 및 KakaoShopping을 포함한 여러 주요 [Kakao](/about-kakao) 서비스를 지원하며, 실시간 활동 데이터 처리를 통해 수천만 명의 사용자에게 서비스를 제공합니다.

**프로덕션 성능:**
- 읽기 지연 시간: &lt;5ms (p99)
- 데이터 규모: 다중 TB 규모 배포
