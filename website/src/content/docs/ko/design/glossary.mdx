Actionbase 문서에서 사용되는 주요 용어.

## 스키마 버전 매핑 {#schema-version-mapping}

v2와 v3는 거의 1:1로 매핑됩니다.

| v2 (현재) | v3 (향후)  | 설명                              |
| --------- | ---------- | --------------------------------- |
| service   | database   | 테이블 그룹화를 위한 네임스페이스 |
| label     | table      | 엣지 스키마 정의                  |
| src       | source     | 누가 인터랙션을 수행했는지        |
| tgt       | target     | 인터랙션을 받은 대상              |
| ts        | version    | 정렬을 위한 타임스탬프            |
| fields    | properties | 엣지 속성                         |
| dirType   | direction  | 방향 유형                         |
| indices   | indexes    | 쿼리 인덱스                       |
| desc      | comment    | 설명                              |

- **스키마 API**: v2 — v3로 마이그레이션
- **쿼리/뮤테이션 API**: v3

## 데이터 모델 {#data-model}

| 용어            | 설명                                                   |
| --------------- | ------------------------------------------------------ |
| **엣지**        | 사용자 인터랙션을 나타내는 관계                        |
| **소스**        | 누가 — 인터랙션을 수행하는 엔티티 (예: user_id)        |
| **타겟**        | 무엇을 — 인터랙션을 받는 엔티티 (예: product_id)       |
| **프로퍼티**    | 엣지에 대한 속성 (예: `created_at`)                    |
| **유니크-엣지** | (source, target) 쌍으로 식별되는 엣지                  |
| **멀티-엣지**   | ID로 식별되는 엣지; (source, target) 쌍당 여러 개 가능 |
| **인덱스**      | 쿼리용 사전 계산된 구조                                |
| **별칭**        | 레이블/테이블의 대체 이름                              |

## 쿼리 및 뮤테이션 {#query-and-mutation}

| 용어          | 설명                                                        |
| ------------- | ----------------------------------------------------------- |
| **COUNT**     | 엣지의 개수를 반환하는 쿼리                                 |
| **GET**       | source와 target로 엣지를 조회하는 쿼리                      |
| **SCAN**      | 사전 계산된 인덱스를 사용하여 엣지를 스캔하는 쿼리          |
| **Start**     | SCAN/COUNT의 시작 노드; OUT일 때는 source, IN일 때는 target |
| **Direction** | `OUT`(source→target) 또는 `IN`(target←source)               |
| **Range**     | 스토리지 레벨의 인덱스 기반 스캔 경계                       |
| **Filter**    | 애플리케이션 레벨에서 조회 후 필터링                        |
| **Version**   | 동시성 및 이벤트 순서를 위한 클라이언트 타임스탬프(ms/ns)   |
| **오프셋**    | 인코딩된 페이지네이션 위치                                  |
| **리밋**      | 최대 결과 수 (25 권장)                                      |

## 쓰기 시점 최적화 {#write-time-optimization}

| 용어             | 설명                              |
| ---------------- | --------------------------------- |
| **엣지스테이트** | 현재 엣지 상태, GET으로 접근      |
| **엣지인덱스**   | 정렬된 인덱스 항목, SCAN으로 접근 |
| **엣지카운터**   | 미리 계산된 카운터, COUNT로 접근  |

## 데이터 파이프라인 {#data-pipeline}

| 용어    | 설명                                         |
| ------- | -------------------------------------------- |
| **WAL** | 내구성과 복구를 위한 Write-Ahead Log         |
| **CDC** | 다운스트림 동기화를 위한 Change Data Capture |
