액션베이스 CLI는 액션베이스 클러스터를 관리하고 유지보수하기 위한 인터페이스를 제공합니다. 메타데이터, 뮤테이션 및 쿼리 작업과의 직접 상호작용을 가능하게 합니다.

## 설치

### Homebrew 사용

액션베이스 CLI를 설치하는 가장 쉬운 방법은 Homebrew를 사용하는 것입니다. 액션베이스 CLI는 [kakao/actionbase](https://github.com/kakao/actionbase) tap을 통해 사용할 수 있습니다:

```bash
brew install kakao/actionbase/tap/actionbase
```

이렇게 하면 CLI의 최신 안정 버전이 설치됩니다. 최신 버전으로 업데이트하려면 다음을 실행하세요:

```bash
brew upgrade actionbase
```

### 수동 설치

또는 [릴리스 페이지](https://github.com/kakao/actionbase/releases)에서 플랫폼에 맞는 최신 릴리스 바이너리를 다운로드할 수 있습니다. 다운로드 후, 바이너리를 실행 가능하게 만들고 PATH의 디렉토리로 이동하세요:

```bash
chmod +x actionbase
sudo mv actionbase /usr/local/bin/
```

## 설정

CLI는 액션베이스 클러스터와 상호작용하기 위해 연결 정보가 필요합니다. 명령줄 플래그를 통해 이를 제공할 수 있습니다:

```bash
actionbase --host <host-url> --authKey <auth-key>
```

예를 들어:

```bash
actionbase --host http://actionbase-cluster.example.com --authKey ***
```
