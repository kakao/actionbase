이 가이드는 액션베이스를 빠르게 시작하는 데 도움이 됩니다.

## 요구사항

- Java 17
- Gradle 7.0+

## 소스에서 빌드

저장소를 클론하고 프로젝트를 빌드하세요:

```bash
git clone https://github.com/kakao/actionbase.git
./gradlew build
```

## 서버 설정 및 실행

액션베이스는 스토리지 백엔드로 HBase가 필요합니다. 다음 옵션 중 하나를 선택하세요:

<Tabs syncKey="hbase-setup">
  <TabItem label="인메모리 HBase (빠른 시작 권장)">
    > <Badge text="참고" variant="caution" /> 인메모리 HBase를 사용하면 데이터가 영구 저장되지 않습니다. 서버가 중지되면 모든 데이터가 손실됩니다. 데이터 영속성이 필요한 경우 대신 로컬 HBase를 사용하세요.
    ### 설정

    액션베이스에는 추가 설정이 필요 없는 내장 인메모리 HBase 구현이 포함되어 있습니다. 이것이 시작하는 가장 간단한 방법입니다.


    ### 서버 실행

    추가 설정 없이 내장 인메모리 HBase 구현을 사용하세요:

    ```bash
    ./gradlew :server:bootRun
    ```

    이것은 기본적으로 인메모리 HBase 구현을 사용합니다.
  </TabItem>
  <TabItem label="Docker Compose를 사용한 로컬 HBase">
    ### 설정

    Docker Compose를 사용하여 로컬에서 HBase 실행:

    ```bash
    cd dev/
    docker compose up
    ```

    이것은 `local` 프로파일과 함께 사용할 수 있는 로컬 HBase 인스턴스를 시작합니다.

    ### 서버 실행

    Docker Compose를 사용하여 HBase를 시작한 경우, `local` 프로파일로 서버를 실행하세요:

    ```bash
    ./gradlew :server:bootRun --args='--spring.profiles.active=local'
    ```
  </TabItem>
</Tabs>

두 경우 모두 서버는 `http://localhost:8080`에서 사용할 수 있습니다.

## 액션베이스 사용

서버가 실행 중이면 두 가지 방법으로 액션베이스와 상호작용할 수 있습니다:

### CLI 사용

액션베이스 CLI를 설치하고 서버에 연결하세요. 설치 지침은 [CLI 문서](/ko/operations/cli/)를 참조하세요.

```bash
actionbase --host http://localhost:8080 --authKey your-auth-key
```

### REST API 사용

`curl` 또는 모든 HTTP 클라이언트를 사용하여 요청을 만들 수도 있습니다. 자세한 엔드포인트 문서는 [API 레퍼런스](/ko/api-references/query/)를 참조하세요.

예제:

```bash
curl http://localhost:8080/api/v1/...
```
