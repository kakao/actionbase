## 1. 엣지 뮤테이션 {#1-edge-mutation}

소스 노드와 타겟 노드 간의 엣지를 변경합니다.

### 엔드포인트 {#endpoint}

```
POST /graph/v3/databases/{database}/tables/{table}/edges
```

### 파라미터 {#parameters}

| 위치 | 파라미터      | 필수 여부               | 설명                             |
| ---- | ------------- | ----------------------- | -------------------------------- |
| 헤더 | Authorization | 선택 사항               | 인증 키(향후 사용을 위해 예약됨) |
| 경로 | database      | 필수                    | 대상 데이터베이스 이름           |
| 경로 | table         | 필수                    | 대상 테이블 이름                 |
| 쿼리 | lock          | 선택 사항(기본값: true) | 뮤테이션 중 락을 획득할지 여부   |
| 바디 | mutations     | 필수                    | 뮤테이션 항목 목록               |

### 요청 바디 {#request-body}

[EdgeBulkMutationRequest](#edgebulkmutationrequest) - 뮤테이션 항목을 포함하는 페이로드

### 응답 타입 {#response-type}

[EdgeMutationResponse](#edgemutationresponse) - 뮤테이션 결과를 포함하는 페이로드

### 요청 예시 {#request-example}

| 파라미터      | 값            |
| ------------- | ------------- |
| Authorization | YOUR_API_KEY  |
| database      | your_database |
| table         | your_table    |
| lock          | true          |

```bash
# POST /graph/v3/databases/your_database/tables/your_table/edges {#post-graphv3databasesyour-databasetablesyour-tableedges}
curl -X POST \
    "http://ab.example.com/graph/v3/databases/your_database/tables/your_table/edges?lock=true" \
    -H "Authorization: YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "mutations": [
        {
          "type": "INSERT",
          "edge": {
            "version": 1,
            "source": "source1",
            "target": "target1",
            "properties": {
              "weight": 0.8,
              "type": "FOLLOWS"
            }
          }
        }
      ]
    }'
```

### 응답 예시 {#response-example}

```json
{
  "results": [
    {
      "source": "source1",
      "target": "target1",
      "status": "CREATED",
      "count": 1
    }
  ]
}
```

## 2. 엣지 뮤테이션 (동기) {#2-edge-mutation-sync}

엣지를 동기 방식으로 뮤테이트합니다. 이 엔드포인트는 응답 전에 뮤테이션이 완료될 때까지 대기합니다.

### 엔드포인트 {#endpoint}

```
POST /graph/v3/databases/{database}/tables/{table}/edges/sync
```

### 파라미터 {#parameters}

| 위치   | 파라미터      | 필수                     | 설명                                |
| ------ | ------------- | ------------------------ | ----------------------------------- |
| Header | Authorization | 선택 사항                | 인증 키 (향후 사용을 위해 예약됨)   |
| Path   | database      | 필수                     | 대상 데이터베이스 이름              |
| Path   | table         | 필수                     | 대상 테이블 이름                    |
| Query  | lock          | 선택 사항 (기본값: true) | 뮤테이션 수행 시 락을 획득할지 여부 |
| Body   | mutations     | 필수                     | 뮤테이션 항목 목록                  |

### 요청 본문 {#request-body}

[EdgeBulkMutationRequest](#edgebulkmutationrequest) - 뮤테이션 항목을 포함하는 페이로드

### 응답 형식 {#response-type}

[EdgeMutationResponse](#edgemutationresponse) - 변이 결과를 포함하는 페이로드

### 요청 예시 {#request-example}

| 파라미터      | 값            |
| ------------- | ------------- |
| Authorization | YOUR_API_KEY  |
| database      | your_database |
| table         | your_table    |
| lock          | true          |

```bash
# POST /graph/v3/databases/your_database/tables/your_table/edges/sync {#post-graphv3databasesyour-databasetablesyour-tableedgessync}
curl -X POST \
    "http://ab.example.com/graph/v3/databases/your_database/tables/your_table/edges/sync?lock=true" \
    -H "Authorization: YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "mutations": [
        {
          "type": "UPDATE",
          "edge": {
            "version": 2,
            "source": "source1",
            "target": "target1",
            "properties": {
              "weight": 0.9,
              "type": "FOLLOWS"
            }
          }
        }
      ]
    }'
```

### 응답 예시 {#response-example}

```json
{
  "results": [
    {
      "source": "source1",
      "target": "target1",
      "status": "UPDATED",
      "count": 1
    }
  ]
}
```

## 이벤트 유형 {#event-types}

뮤테이션 항목의 `type` 필드는 수행할 작업을 지정합니다:

| 유형     | 설명                                                             |
| -------- | ---------------------------------------------------------------- |
| `INSERT` | 새로운 엣지를 생성하거나 기존 엣지를 새 버전으로 업데이트합니다. |
| `UPDATE` | 기존 엣지의 프로퍼티를 업데이트합니다.                           |
| `DELETE` | 엣지를 삭제합니다(삭제 표시).                                    |

## Lock Parameter {#lock-parameter}

`lock` 파라미터는 변이(mutation) 시 락을 획득할지 제어합니다:

- **true (기본값)**: 락을 획득하여 동시 수정을 방지합니다. 데이터 일관성을 보장하지만 지연 시간이 더 길 수 있습니다.
- **false**: 락을 건너뜁니다. 더 빠르지만 여러 변이가 동일한 엣지를 동시에 대상으로 할 경우 경쟁 조건이 발생할 수 있습니다.

**Note:** It is recommended to use `lock=true` in production environments to ensure data consistency.

## 데이터 모델 {#data-model}

### EdgeBulkMutationRequest {#edgebulkmutationrequest}

엣지 변이 요청 페이로드입니다.

```kotlin
data class EdgeBulkMutationRequest(
  val mutations: List<MutationItem>, // List of mutation items
) {
  data class MutationItem(
    val type: EventType,        // Event type (INSERT, UPDATE, DELETE)
    val edge: Edge,             // Edge data
  )
}
```

### MultiEdgeBulkMutationRequest {#multiedgebulkmutationrequest}

다중 엣지 변이 요청 페이로드입니다.

```kotlin
data class MultiEdgeBulkMutationRequest(
  val mutations: List<MutationItem>, // List of mutation items
) {
  data class MutationItem(
    val type: EventType,        // Event type (INSERT, UPDATE, DELETE)
    val edge: MultiEdge,        // Multi-edge data
  )
}
```

### EdgeMutationResponse {#edgemutationresponse}

엣지 변이 응답 페이로드입니다.

```kotlin
data class EdgeMutationResponse(
  val results: List<Item>,      // List of mutation results
) {
  data class Item(
    val source: Any,            // Source node ID
    val target: Any,            // Target node ID
    val status: String,         // Mutation status (e.g., CREATED, UPDATED, DELETED)
    val count: Int,             // Number of edges affected
  )
}
```

### MultiEdgeMutationResponse {#multiedgemutationresponse}

다중 엣지 변이 응답 페이로드입니다.

```kotlin
data class MultiEdgeMutationResponse(
  val results: List<Item>,      // List of mutation results
) {
  data class Item(
    val id: Any,               // Edge ID
    val status: String,         // Mutation status (e.g., CREATED, UPDATED, DELETED)
    val count: Int,             // Number of edges affected
  )
}
```

### Edge {#edge}

변이를 위한 개별 엣지 정보입니다.

```kotlin
data class Edge(
  val version: Long,                 // Edge version
  val source: Any,                   // Source node ID
  val target: Any,                   // Target node ID
  val properties: Map<String, Any?>, // Edge properties
)
```

### MultiEdge {#multiedge}

변이를 위한 개별 다중 엣지 정보입니다.

```kotlin
data class MultiEdge(
  val version: Long,                 // Edge version
  val id: Any,                       // Edge ID
  val source: Any? = null,           // Source node ID (optional)
  val target: Any? = null,           // Target node ID (optional)
  val properties: Map<String, Any?>,  // Edge properties
)
```
