Welcome to the Actionbase community! We're excited to have you here. Actionbase is an open-source project, and we welcome contributions, feedback, and participation from developers around the world.

## Get Involved

There are many ways to get involved with the Actionbase community:

- **Contribute Code**: Help improve Actionbase by submitting pull requests
- **Report Issues**: Help us identify bugs and suggest improvements
- **Share Ideas**: Participate in discussions and share your use cases
- **Improve Documentation**: Help make our documentation better
- **Help Others**: Answer questions and help fellow community members

## Community Channels

### GitHub

Actionbase is hosted on GitHub, where all development happens:

- **Repository**: [https://github.com/kakao/actionbase](https://github.com/kakao/actionbase)
- **Issues**: [Report bugs or request features](https://github.com/kakao/actionbase/issues)
- **Discussions**: [Ask questions and share ideas](https://github.com/kakao/actionbase/discussions)

For detailed information about contributing, see our [GitHub Guide](/community/github/).

## Code of Conduct

We are committed to providing a welcoming and inclusive environment for all community members. Please read our [Code of Conduct](/community/code-of-conduct/) to understand our community standards and expectations.

## Getting Help

- **Documentation**: Check our [documentation](/introduction/) for guides and API references
- **GitHub Issues**: Search existing issues or create a new one
- **GitHub Discussions**: Ask questions and share ideas with the community

## Recognition

We value and recognize all contributions to Actionbase. Contributors are recognized in:

- Release notes
- Contributors list
- Project documentation

Thank you for being part of the Actionbase community!
